FindDuplicates 📱

FindDuplicates is an Android app that detects exact duplicate photos and videos and identifies visually similar photos using on-device AI.

✨ Features
- Exact Duplicate Detection: Uses SHA-256 hashing to identify identical photos and videos.
- AI-Powered Similar Photo Detection: Uses image embeddings and cosine similarity to find visually similar photos.
- On-Device AI: Runs a LiteRT model based on MobileNetV3 for image feature extraction.
- Modern UI:** Built with Jetpack Compose.
- Background Processing: Uses Kotlin Coroutines for scanning and processing.

 🛠️ Tech Stack
- Kotlin
- Jetpack Compose
- Android MediaStore
- LiteRT & MobileNetV3
- SHA-256 Hashing
- Image Embeddings & Cosine Similarity
- Kotlin Coroutines

 🎯 Goal
To make duplicate media cleanup smarter by combining traditional file comparison with AI-powered visual similarity detection.
